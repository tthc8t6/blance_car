# 批次子 agent 的 prompt 模板

把 `{…}` 换成实际内容后整段作为 Agent 的 prompt。所有批次的 agent 在同一条消息里并行派出，`model: "sonnet"`。

---

你在帮用户把一门课的截图整理成学习笔记。这是其中的**批次 {批次名}**，其他批次由别的 agent 并行处理，最后会合并起来。

**课程 / 主题**：{例如：B 站《平衡车》7.x 倒立摆参数整定}
**用户的目标**：{例如：在 MATLAB 里一步步复现老师推导 PID 传递函数的过程}
**本批图片**（已转正、压缩到 1600px，按顺序）：
{逐行列出完整绝对路径，例如 D:\倒立摆_参数整定\images\IMG_4734.jpg}

**相邻批次的大致内容**（用来衔接，不要重复写）：{上一批讲到哪里 / 下一批从哪里开始，没有就写"无"}

**原图目录**：{原图目录}。**只读**，不要在里面写任何文件。
**放大图存放处**：{scratchpad 目录}，放大的局部图都存在这里，不要存进笔记目录。

## 怎么做

1. 每张图**只完整读一次**。某个字符需要放大看时，用下面的命令截局部再读，不要反复读整张图：
   `python "C:\Users\tth\.claude\skills\screenshots-to-notes\scripts\prep_images.py" crop <图片> <左> <上> <右> <下> --out <放大图存放处>\<名字>.png`
   四个参数是 0~1 的比例，`<图片>` 优先用原图（分辨率更高）。放大后还是认不出，就标【看不清】。
   本机控制台是 cp1252 编码，中文会变成 `?`。中文内容写进 UTF-8 文件，再用 Read 工具读回来。
2. 按**内容逻辑**而不是截图顺序组织。同一张框图逐步加批注的连续几帧，合成一节写，并说明每一帧加了什么。
3. 把推导写到用户能照着复现的程度：每个式子从哪来、做了什么变换、哪些量是直接给出的，都要写清楚。

## 硬性规则

- **看不清就标【看不清】，不要猜。** 能看出形状的写"形似 X"，并说明为什么不确定。
- 不确定的地方分三类：
  - **A 内容存疑**：字看清了，但推导或数值可疑（符号方向、无依据的数值跳变）
  - **B 字符看不清**
  - **C 标注含义不明**：圆圈、箭头这类没配文字的强调
- 老师跳过的推导**照实写"直接给出"**，不要替老师补。想补充可能的依据时，单独写一段并标成「推测」。
- 弹幕、观众评论和老师原话分开写，弹幕标明"弹幕"。弹幕里的字看不清归入 B 类；弹幕提出的质疑写进「本批逻辑断层」。
- 发现图片和任务描述不符（比如不是板书而是录屏），在文件开头说明。

## 输出

写到 `{笔记目录}\_parts\_part_{批次名}.md`，UTF-8 编码，结构如下：

```markdown
# 批次 {批次名}：IMG_xxxx ~ IMG_yyyy（{主题}）

> 本文件由批次 {批次名} agent 生成，待合并进 {总笔记文件名}。

## 第 N 步：{小节标题}

> 来源：IMG_xxxx

![IMG_xxxx](images/IMG_xxxx.jpg)

{正文，公式用 $...$ / $$...$$}

---

## 本批存疑汇总

| 类别 | 图片 | 位置 | 内容 |
|---|---|---|---|
| A/B/C | IMG_xxxx | 图中哪个位置 | 看到了什么、为什么不确定 |

## 本批逻辑断层

| 断层 | 位置 |
|---|---|
```

最后回复一句话：写到了哪个文件、共几节、A/B/C 各几处。**不要把笔记正文贴进回复。**
