# 总笔记的结构

范例：`D:\倒立摆_参数整定\study_video-notes.md`。文件布局：

```
<笔记目录>\
├── <笔记名>.md            ← 合并后的总笔记（= _front.md + 各 _part 正文）
├── images\                ← prep_images.py 输出的 1600px 转正图 + manifest.json
└── _parts\
    ├── _front.md          ← 总笔记的开头部分（下面的 1~6 节）
    ├── _part_0.md, _part_A.md …   ← 各批次分段稿
    ├── _part_X.old.md     ← 重读前的旧稿
    └── <笔记名>.prev.md   ← 上一版总笔记
```

## _front.md 的各节（按顺序）

### 1. 标题与来源

```markdown
# {主题} —— 学习笔记

> 整理自 `{图片目录}` 下 N 张{录屏截图/照片}，目标是{用户目标}。
>
> 生成日期：YYYY-MM-DD
```

### 2. 怎么用这份笔记

- ① Typora：文件 → 偏好设置 → Markdown → 勾选「内联公式」→ **重启**。块级 `$$` 不受影响
- ② 每一小节附了原图，已按 EXIF 方向转正（注明有几张原本是倒的），嵌入的是 `images/` 下的 1600px 版
- ③ 先看核对清单，再看正文

### 3. ⚠️ 核对清单

汇总各批次的「本批存疑汇总」，**按类别重新编号**：

- **A. 内容存疑**（优先核对，会影响复现结果）：每条单独一个小标题，写清现象、为什么有问题、
  影响到哪里、怎么核对（例如"回看视频讲第 (1) 式的那一段"）
- **B. 字符看不清**：表格，列为 `# | 图片 | 位置 | 看到的形状 / 困惑`
- **C. 标注含义不明**：表格，同上，注明优先级低

用户核对完、回填结论后，标题改成 `✅ 核对说明（已全部核实）`，每条后面补上结论。

### 4. 关键结论速查

最终参数、核心公式、"你手上那个式子是什么"这类用户最常回来查的东西，用表格写。

### 5. 推导路线图

如果老师有章节大纲，用表格对照：`老师的章节 | 本笔记第几部分 | 图片范围`。
注明推导**终止在哪**：最后一张图是不是收尾帧、还缺哪些内容没拍到。

### 6. 已知的逻辑断层汇总

汇总各批次的断层表，统一编号。弹幕里的质疑附在后面，标明是弹幕。

## 正文

由 `prep_images.py merge` 生成，不要手工拼接。它做的事：

- 各 `_part_*.md` 按 `0, A, B…` 顺序拼接，每批之间用 `---` 分隔
- 去掉分段稿开头"本文件由批次 X agent 生成"那一行，以及已经搬进 `_front.md` 的
  「本批存疑汇总」「本批逻辑断层」两节
- 标题整体降一级：`# 批次 A` → `## 批次 A`，`## 第 N 步` → `### 第 N 步`。
  所以全文只有 `_front.md` 开头的那一个一级标题，Typora 大纲不会乱

正文里的【看不清】标记保留，方便用户对照核对清单找到原处。
